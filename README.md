# Unity Obstacle Runner

## Overview

Unity Obstacle Runner is a simple first-person game developed as a personal project. The player moves automatically through a level while avoiding obstacles using mouse and keyboard controls.

## Features

- First-person camera
- Automatic forward movement
- Obstacle avoidance gameplay
- Collision detection
- Simple level design
- Scoring system
- Main and pause menus

## Technologies

- Unity
- C#


## Future Improvements

- Multiple levels
- Sound effects
- Improved graphics
